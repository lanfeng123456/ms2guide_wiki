# Mortal Shell II guide

> 素材核对日期：2026-08-19

## 搜索意图

综合新手攻略：战斗、防御、Shell、武器、升级、探索、死亡惩罚与首个区域路线。

## 已核验素材

- 游戏取消传统 stamina bar，核心战斗围绕姿态破坏、暴击、处决、Seal 与不同防御方式展开。
- Shell 是职业与构筑核心；玩家发现尸身后可 possession，并用 Shell Points 或 Glimpses 强化能力。
- Tiel 是 Beta 中可发现的首个主要 Shell，其 Perfect Dodge 可触发隐身类效果。
- Beta 路线包括序章、Tar Golem、Marrow Keep、Beacons、可选地牢和 Magdalena 区域。
- 武器、sidearms 与 Tarstones 共同决定输出和 Resolve 消耗方式。

5. Beacon、Marrow Keep 与探索循环
6. Tarstone 和 sidearm 入门
7. 前三小时易错点
